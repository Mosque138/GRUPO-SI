## ¿Qué ROL es el encargado de capturar estos datos?

El Administrador del Sistema de Gestión de Pedidos a Domicilio (SGPD) es el encargado de registrar y actualizar la información de usuarios, pedidos y productos dentro de la plataforma.


## ¿Qué FUNCIÓN de validación debe realizar el sistema automáticamente?

El sistema debe validar lo siguiente:

- No registrar datos vacíos o incorrectos.
- Verificar correos y números telefónicos válidos.
- No permitir pedidos de productos no disponibles.
- Registrar correctamente pagos y pedidos.
- Permitir el acceso según el rol de cada usuario.


## ¿Qué sucede con la información del sistema si este Rol no cumple su Función?

- Los pedidos podrían registrarse incorrectamente.
- Los reportes del sistema serían erróneos.
- Habría problemas en las entregas y pagos.
- El sistema perdería calidad y confiabilidad en la información.
